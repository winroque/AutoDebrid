⚡ AutoDebrid — Política de Privacidade / Privacy Policy

Última atualização / Last updated: 2026-08-17

Português

A extensão AutoDebrid não coleta, armazena em servidores próprios, vende ou compartilha nenhum dado pessoal. Não há telemetria, analytics nem anúncios.

  • Chave de API do Real-Debrid: fornecida por você, é armazenada exclusivamente no armazenamento do navegador (chrome.storage.sync), que pode sincronizá-la entre seus dispositivos através da sua própria conta do navegador. Ela é enviada apenas para api.real-debrid.com via HTTPS, unicamente para autenticar as requisições que você inicia.
  • Links das páginas: a extensão lê os links (URLs) das páginas que você visita apenas localmente, para identificar quais pertencem a hosters suportados. Nenhum conteúdo de página é enviado a lugar algum. Um link individual só é enviado a api.real-debrid.com quando você pede para convertê-lo (clique, badge ⚡ ou popup).
  • Preferências: as opções da extensão ficam no armazenamento do navegador.
  • Terceiros: o único serviço externo contatado é a API oficial do Real-Debrid. O uso do Real-Debrid é regido pelos termos e pela política de privacidade deles.
  • Remoção: desinstalar a extensão (ou limpar seus dados no navegador) remove a chave e as preferências.

Esta extensão não é afiliada ao Real-Debrid. Contato: abra uma issue em github.com/winroque/AutoDebrid.

English

The AutoDebrid extension does not collect, store on its own servers, sell, or share any personal data. There is no telemetry, analytics, or advertising.

  • Real-Debrid API key: provided by you and stored exclusively in the browser's storage (chrome.storage.sync), which may sync it across your devices through your own browser account. It is sent only to api.real-debrid.com over HTTPS, solely to authenticate requests you initiate.
  • Page links: the extension reads link URLs on pages you visit locally only, to identify which belong to supported file hosters. No page content is sent anywhere. An individual link is sent to api.real-debrid.com only when you ask to convert it (click, ⚡ badge, or popup).
  • Preferences: extension options are kept in browser storage.
  • Third parties: the only external service contacted is the official Real-Debrid API, governed by its own terms and privacy policy.
  • Removal: uninstalling the extension (or clearing its browser data) removes the key and preferences.

This extension is not affiliated with Real-Debrid. Contact: open an issue at github.com/winroque/AutoDebrid.
